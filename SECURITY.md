# Security policy

To report a security problem with pwned.coffee itself (the site, the API or the MCP server), email **security@pwned.coffee** with what you found and how to reproduce it. Don't open a public issue. See [security.txt](https://pwned.coffee/.well-known/security.txt) and [pwned.coffee/about#disclosure](https://pwned.coffee/about#disclosure).

A vulnerability in someone else's product goes to that vendor or to a [CVE Numbering Authority](https://www.cve.org/ResourcesSupport/ReportRequest).

A wrong or missing entry on the board isn't a security problem: use the [wrong-entry form](../../issues/new?template=wrong-entry.yml) or email chef@pwned.coffee.
